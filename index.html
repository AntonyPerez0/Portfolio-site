Arena courses↗

Free courses in C/C++, Java, Rust and Python where every exercise is compiled and run for real in your browser: Clang 20 in WebAssembly, javac 21 on a Rust JVM, the real rustc grading every test, and CPython 3.14 through Pyodide. No account needed.

TypeScript · WebAssembly · GitHub Actions · WCAG 2.2 AA

  • cpparena.com↗
  • javaarena.com↗
  • rustarena.app↗
  • pythonarena.org↗
How it works
  • No hand-typed answers. The build runs every reference solution on the real toolchain, then CI replays them in the browser engine and fails on any difference.
  • Static and serverless. Progress stays in the browser, and every course works offline once visited.
  • Graded like real work. A Pro Track is graded by GitHub Actions in the learner’s own repository, and RustArena grades test-writing with planted mutants.
  • Accessible. WCAG 2.2 AA, with axe scans of every page type.
  • Source. cpp-arena, Java-Arena, RustArena and pythonarena on GitHub.

SortiePrep↗

A cockpit trainer for DCS World. You click the real switches on real cockpit images, and a simulated aircraft underneath decides when each checklist step is actually done. Two airframes, 409 procedure steps, 100+ monthly visitors.

JavaScript · State machines · PWA · Cloudflare Workers

  • sortieprep.com↗
  • Source↗
How it works
  • Aircraft-agnostic core. A switch state machine, an event bus and a hotspot and pan-zoom view layer; each airframe is a data module, so new jets drop in.
  • The jet decides. The F/A-18C simulates the APU, both F404 engines, generators, hydraulics, bleed air and INS, so 109 steps confirm themselves off aircraft state.
  • Tested headless. Test suites drive every procedure to completion through the real sim and exercise failure paths such as a hung start.
  • Runs anywhere. An installable PWA with offline caching, plus a presence API on Cloudflare Workers and D1.

Anomaly Grove↗

A grow-and-steal tycoon live on Roblox: grow glowing cores, steal them from rival bases and survive monster-filled nights. 24,000 lines of strict-typed Luau across 142 modules, covered by 240 tests.

Luau (strict) · Roblox · Python simulation

  • Play on Roblox↗
  • Source↗
How it works
  • Server-authoritative. Every client request is checked for type, range, reach, cooldown and ownership, backed by a security audit of the remote handlers.
  • Saves that survive. Schema-versioned saves with migrations, retries and session locking, so a player hopping servers never loads stale data.
  • Tuned by simulation. Economy pacing comes from a Python simulation of about 1,200 hours of play.

Job Autopilot↗

A desktop app for macOS and Windows that finds jobs that fit you, builds a one-page résumé for each from lines you approved, then fills in and sends the application. The AI may only reword your facts, never add to them.

Electron · Playwright · LLM guardrails · Ollama

  • Download↗
  • Source↗
How it works
  • Honest by design. Rule-based checks with no AI involved reject any number, tool or claim you didn’t give, and a second AI pass fact-checks every line.
  • Real application forms. It fills Greenhouse, Lever, Ashby, SmartRecruiters, Workable and multi-page forms, starts in dry run and never applies to the same job twice.
  • Local first. No accounts and no analytics. Bring your own AI key, about a cent per application, or run a local model through Ollama or LM Studio.

GitOps homelab↗

Bare-metal Kubernetes in my home, managed entirely from Git. Talos Linux, FluxCD and Kustomize run 18 self-hosted services, from CI/CD and automation to local AI, with runtime threat detection and nightly backups.

Kubernetes · Talos Linux · FluxCD · Falco · Prometheus

  • Source↗
How it works
  • Immutable nodes. Talos Linux has no SSH and no shell, so the cluster can’t drift from its configuration.
  • Git is the source of truth. FluxCD reconciles every change from a commit; if it isn’t in Git, it doesn’t exist.
  • Watched and backed up. Falco on the eBPF driver streams syscall-level detections, Prometheus and Grafana watch the rest, and CloudNativePG runs PostgreSQL 16 with nightly self-auditing backups.
