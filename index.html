Arena courses↗

Free courses in C/C++, Java, Rust and Python where every exercise is compiled and run for real in your browser: Clang 20 in WebAssembly, javac 21 on a Rust JVM, the real rustc grading every test, and CPython 3.14 through Pyodide, with no account needed. TypeScript · WebAssembly · GitHub Actions · WCAG 2.2 AA

  • cpparena.com↗
  • javaarena.com↗

02Flight-sim trainer

SortiePrep↗

A cockpit trainer for DCS World. You click the real switches on real cockpit images, and a simulated aircraft underneath decides when each checklist step is actually done. It covers two airframes and 409 procedure steps.

JavaScript · State machines · PWA · Cloudflare Workers

  • sortieprep.com↗
  • Source↗
How it works
  • Aircraft-agnostic core. A switch state machine, an event bus and a hotspot and pan-zoom view layer; each airframe is a data module, so new jets drop in.
  • The jet decides. The F/A-18C simulates the APU, both F404 engines, generators, hydraulics, bleed air and INS, so 109 steps confirm themselves off aircraft state.
  • Tested headless. Test suites drive every procedure to completion through the real sim and exercise failure paths such as a hung start.
  • Runs anywhere. An installable PWA with offline caching, plus a presence API on Cloudflare Workers and D1.

03Multiplayer game

Anomaly Grove↗

A grow-and-steal tycoon live on Roblox: grow glowing cores, steal them from rival bases and survive monster-filled nights. 24,000 lines of strict-typed Luau across 142 modules, covered by 240 tests.

Luau (strict) · Roblox · Python simulation

  • Play on Roblox↗

How it works
  • Server-authoritative. Every client request is checked for type, range, reach, cooldown and ownership, backed by a security audit of the remote handlers.

04Data pipeline

CS2 Pro Configs↗

My most-visited site, with 16,000+ visitors a month. It serves the settings of 620 Counter-Strike 2 pros as ready-to-paste console commands, with every crosshair converted to the game’s new crosshair system and a sensitivity matcher for your mouse’s DPI.

Python · Node.js · Static site generation · GitHub Actions

  • copyprosta.com↗
  • Source↗
How it works
  • Converted, not copied. CS2’s September 2026 update replaced the crosshair system, so each pro’s old crosshair is converted at their own resolution with a pinned community converter, and tests check it against crosshairs pros were seen using after the update.
  • Pastes that fit. CS2’s console rejects lines over 510 characters, so long configs come in parts; every copy button stays at 500 characters or less, and the build fails if one doesn’t.
  • Checked against the game. Every command is validated against CS2’s own convar list: removed or cheat-protected settings are dropped, renamed ones are renamed and out-of-range values are clamped.
  • Rebuilt every week. A GitHub Action scrapes settings.gg, reconverts every crosshair, regenerates the 620 prerendered player pages and runs the site’s tests before it commits.

05Infrastructure

GitOps homelab↗

Bare-metal Kubernetes in my home, managed entirely from Git. Talos Linux, FluxCD and Kustomize run 18 self-hosted services, from CI/CD and automation to local AI, with runtime threat detection and nightly backups.

Kubernetes · Talos Linux · FluxCD · Falco · Prometheus

  • Source↗
How it works
  • Immutable nodes. Talos Linux has no SSH and no shell, so the cluster can’t drift from its configuration.
  • Git is the source of truth. FluxCD reconciles every change from a commit; if it isn’t in Git, it doesn’t exist.
  • Watched and backed up. Falco on the eBPF driver streams syscall-level detections, Prometheus and Grafana watch the rest, and CloudNativePG runs PostgreSQL 16 with nightly self-auditing backups.
